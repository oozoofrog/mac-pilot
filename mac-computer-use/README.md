# Mac Computer Use

Operate Mac apps, browser pages, iOS web views, physical iPhones and Apple Watch with the mac-cu MCP server. Use for desktop UI tasks without a better API or CLI, web view inspection, input and screenshots on a connected iPhone or paired Apple Watch, or mac-cu setup, modes and simulator preparation. Route iOS Simulator app launch, logs, test data and change verification through simulator-pilot.

The native simulator LCD keeps content opaque and groups actions in right and bottom Liquid Glass toolbars. See [device window controls](skills/mac-computer-use/references/device-window.md) for the single hinge slider, input, inspection and capability availability.

For a paired Apple Watch, select its UUID with `device allow` to start a signed watchOS XCTest session, capture its screen or send coordinate input. A connected physical iPhone is operated with the `device` tool and watched in Xcode's Device Hub; see [physical iPhone](skills/mac-computer-use/references/physical-device.md).

See [skill and setup](skills/mac-computer-use/SKILL.md) and [installation](skills/mac-computer-use/README.md).

The source package preserves the supplied layout, author and MIT attribution. This directory is the installable package; there is no duplicate distribution mirror. Releases omit generated executables, caches, development evidence and private runtime state.

상태·키보드·기기별 대응
접기는 접이식 기기에만 표시합니다. Watch에서는 회전·접기 자리를 Crown 조작으로 대체하고, 지원하지 않는 생체 인증·위치·오디오는 메뉴에서 이유와 함께 비활성화합니다. 기기가 바뀌어도 보편적인 홈·캡처·입력·보기 위치는 유지합니다.
툴바는 Tab으로 진입하고 방향키로 항목 간 이동, Enter/Space로 실행합니다. 팝오버는 첫 컨트롤에 초점을 두며 Escape로 닫으면 원래 버튼으로 돌아옵니다. 슬라이더는 ←/→ 1°, Shift+←/→ 10°, Home 0° / End 180°입니다. 같은 슬라이더의 0°·90°·180° 눈금을 클릭하면 해당 각도가 적용됩니다. Page Up / Page Down은 다음 / 이전 주요 눈금으로 이동합니다.
명령 처리 중에는 해당 조작을 잠그고 완료 응답 전까지 기존 값을 유지합니다. 실패하면 마지막 확인값과 선택 초안을 남기고 동일 목표로 재시도합니다. 미연결에서는 기기 명령을 잠그고 다시 연결 / 기기 관리 진입점을 남깁니다. 녹화 중에는 정지·시간·텍스트를 함께 표시합니다. 좁은 창의 하단 툴바는 줄바꿈 대신 가로 스크롤을 사용합니다.
